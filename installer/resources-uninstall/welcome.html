Désinstaller Tresses

Ce programme retire de ton Mac :

  • le plugin VST3 Tresses ;
  • l'application Tresses ;
  • les deux firmwares fournis (les fichiers que tu as ajoutés toi-même dans ce dossier sont gardés) ;
  • les réglages de l'application.

Tes projets Reason ne sont pas touchés. Ferme Reason avant de continuer.

macOS parle d'« installation » dans les étapes suivantes : c'est normal, c'est son vocabulaire.
