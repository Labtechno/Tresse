Tresses

Un module Braids de Mutable Instruments, émulé, pour Reason et les autres logiciels qui lisent les plugins VST3.

Cet installateur pose :

  • le plugin VST3, là où Reason le trouve ;
  • l'application Tresses, pour jouer sans Reason ;
  • deux firmwares à essayer (Braids 1.9 et Bees-in-the-Trees 4.1), dans Utilisateurs > Partagé > Tresses > Firmwares.

Si une version de Tresses est déjà installée, elle est remplacée. Pense à fermer Reason avant de continuer.
